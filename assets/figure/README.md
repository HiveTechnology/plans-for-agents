# The figure

`plans-loop.workflow.json` is the diagram source, in
[archify](https://github.com/tt-a1i/archify)'s workflow format.
`hive-tokens.css` restyles archify's editorial preset to the Hive Technology
design register: paper and plinth grounds, gold as the only accent, Geist Mono
and Outfit. Render with archify, append the token sheet to the delivered HTML,
open it with `?theme=light&present=1`, and export.
